## 1. 投稿设置（投稿页逐项照填）

| 项 | 填什么 | 为什么 |
| --- | --- | --- |
| 分区 | **动画 → 综合** | 动画区规则明写「图包类视频请投稿至动画区-综合」。若你更想按"同人图"投，备选 **生活 → 绘画**（该区允许转载，但严禁盗图冒充自制） |
| 创作类型 | **转载**（不要选自制） | 165 张图来自 41 位作者，属于搬运/汇编；生活区绘画规则原文「严禁盗图冒充自制」，选错会被下架 |
| **创作声明** | **该视频使用人工智能合成技术** ⚠️ | 配音为 AI 合成语音。按《人工智能生成合成内容标识办法》（2025-09-01 施行），音频属生成合成内容；B 站投稿页有这个选项，**必须主动勾选**。不勾的话平台仍会按社区规则自动加标识，且不得恶意隐匿 |
| 标题 | `【转载】DeepSeek 鲸鱼娘 · 社区画廊 165 张图集（41 位作者，逐图署名）` | 转载稿件标题需带【转载】+ 来源/作者 |
| 封面 | `cover.jpg` | 规则要求「封面应与视频内容一致，优先使用截图」 |
| 标签 | `DeepSeek` `鲸鱼娘` `AI绘画` `绘画` `图包` `壁纸` `静态网站` `GitHubPages` | 标签要准确，第一位放主题 |
| 可见范围 | **公开（所有人可见）** | 传播最大化；别设为"仅粉丝可见"，否则外链更难被发现 |
| 允许转载 | 建议**开启**，但注明「请保留署名与链接」 | CC BY-NC-SA 的 SA 条款要求衍生作品同协议开放 |
| 字幕 | 上传 `galaxy-tour-56s.srt` | AI 配音必须配字幕，否则静音观看体验差 |

## 5. 合规自查清单（投稿前对一遍）

- [ ] 创作类型选了「转载」，**没有**选「自制」
- [ ] **创作声明勾选了「该视频使用人工智能合成技术」**（配音为 AI 合成，必勾）
- [ ] 标题带「【转载】」前缀
- [ ] 简介里有**转载来源链接** + **作者信息**（指向仓库 / ATTRIBUTION.md）
- [ ] 简介里提供了**下载方式**（规则：图包类视频若提供下载方式，必须在简介中提供）
- [ ] 简介里写明了**素材来源**（鲸鱼娘开源资产库）与**许可**（CC BY-NC-SA 4.0）
- [ ] 简介里写明了**配音为 AI 合成语音**
- [ ] 没有接广告 / 没有带货（会构成商业使用，违反 NC 条款）
- [ ] 没有开"付费/充电专属"以外的特殊权限，也没有把内容做成"独家资源"暗示
- [ ] 封面用的是自己页面的截图，与视频内容一致
- [ ] 视频 ≥ 1 分钟（本片 56 秒）
- [ ] 已上传 `galaxy-tour-56s.srt` 字幕（AI 配音必须配字幕）
- [ ] BGM 素材已按规范注明（本片无 BGM，已在简介写明）
