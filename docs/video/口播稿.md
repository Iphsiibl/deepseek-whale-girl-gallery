## 配音参数

| 项 | 值 |
| --- | --- |
| 音色 | `female-yujie`（御姐音色） |
| 情绪 | `neutral`（**全段统一**） |
| 语速 | `0.95` |
| 后期 | `loudnorm I=-16 TP=-1.5` + `alimiter 0.95` |
| 采样率 | 48kHz 立体声（成片 96kHz AAC 192kbps） |

### 音色怎么选才"与视频相符"

视频是深海蓝、安静、精致的技术画廊，讲解节奏偏慢（3.8 字/秒）。
候选音色里 `female-yujie`（御姐）最搭：温和知性、不抢画面，
比播报腔更符合安静的技术导览，又比校园音更有质感。

| voice_id | 名称 | 评价 |
| --- | --- | --- |
| `female-yujie` | 御姐音色 | **本片采用**，温柔知性 |
| `Chinese (Mandarin)_Gentleman` | 温润男声 | 备选，技术感更强 |
| `danya_xuejie` | 淡雅学姐 | 备选，更素净 |
| `Chinese (Mandarin)_Male_Announcer` | 播报男声 | 不建议，过于正式 |

### ⚠ 一个踩过的坑

第 9 句最初设了 `emotion: "happy"` 想让收尾提一提精神，
结果 **音色从御姐突变成高尖童声**（转录模型专门指出了这点）。
`emotion` 参数会连带改变音色本身，**解说类视频全程用 `neutral`**。
